# Raw — неизменяемые исходные материалы

Храните здесь только материалы, которые разрешено сохранять. После добавления не редактируйте, не переименовывайте и не перемещайте файл. Для исправления/аннотации создайте отдельную заметку. Для защищённых статей, закрытых данных и конфиденциальных рукописей храните разрешённую ссылку и метаданные, а не копию. Не включайте частные материалы в публичный Git.
