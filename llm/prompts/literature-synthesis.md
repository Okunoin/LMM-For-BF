# Промпт: синтез литературы

Синтезируй только перечисленные проверенные источники. Для каждого сравнивай вопрос, систему, метод, условия, результат и ограничения. Указывай точные ссылки на source-карточку и страницы/разделы. Различай выводы авторов, согласие между работами и собственный синтез. Покажи противоречия и возможные методические причины; не объявляй отсутствие найденных публикаций отсутствием исследований. Не выдумывай библиографию. Результат — структура синтеза и список пробелов для проверки человеком.

Тема и разрешённые источники: _указать_.
