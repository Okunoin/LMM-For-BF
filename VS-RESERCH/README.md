# Research OS — база исследовательской работы

Рабочее пространство Obsidian для анализа научных статей и данных, планирования физических исследований, подготовки грантовых заявок и научных рукописей. Система разделяет исходные доказательства, скомпилированное знание, рабочие проекты и результаты. ИИ помогает обрабатывать материалы, но не становится источником истины и не заменяет авторскую ответственность.

## Модель

```text
raw/ (источники и данные, не менять) ──→ wiki/ (проверяемое знание)
                 │                                  │
                 └──→ research/ и projects/ ←───────┘
                         │
              grants/ и manuscripts/ (результаты)
                         ↑
              LLM помогает, человек проверяет
```

## Начало работы

1. Откройте папку в Obsidian через **Open folder as vault**.
2. Прочитайте `AGENTS.md`, `AI_POLICY.md` и `CONTRIBUTING.md`. Это правила для будущей работы ИИ и человека внутри этого vault.
3. Заполните профиль ниже и настройте резервное копирование. Не помещайте секреты и материалы без прав в синхронизируемый vault.
4. Для каждой статьи создайте карточку в `wiki/sources/`; храните оригинал в `raw/` только если это разрешено. Внесите запись в `log/ingest.md`.
5. Начинайте новые исследования в `research/`, грантовые заявки — в `grants/`, статьи — в `manuscripts/`.

## Карта папок

| Папка | Назначение |
| --- | --- |
| `raw/` | Первичные статьи, разрешённые данные, лабораторные записи; неизменяемые доказательства |
| `wiki/` | Проверяемые карточки источников, понятия, методы, модели и синтез литературы |
| `research/` | Гипотезы, планы и дневники отдельных исследований |
| `projects/` | Более широкие проекты, протоколы, результаты и решения |
| `grants/` | Конкурсы, требования, черновики заявок, бюджеты и проверка соответствия |
| `manuscripts/` | Научные статьи, версии, структура, рисунки и контроль утверждений |
| `llm/` | Промпты, запросы, выбранные ответы и оценка качества ИИ |
| `log/` | Append-only журналы источников, запросов и использования ИИ |
| `templates/` | Шаблоны заметок Obsidian |

Начинайте с `wiki/index.md`. Полный процесс описан в `CONTRIBUTING.md`.
