# LLM — воспроизводимое использование ИИ

- `prompts/` — проверенные роли и инструкции.
- `queries/` — конкретные задачи, контекст и проверки.
- `outputs/` — временные ответы, исключённые из Git.
- `evaluations/` — рубрики качества.

Передавайте минимальный разрешённый контекст. ИИ не является научным источником; проверяйте вывод по оригинальным данным и публикациям.
